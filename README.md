# Olist_Ecommerce_-SQL_Analytics_Project-
This project analyzes brazillian e commerce dataset using sql  to uncover key business insight related to revnue drivers , cutomer purchasing behaviour , product performance and seller contribution
The Goal is to stimulate how data analyst wold explore multi-table transactional data and translate buiness question into sql 

# Dataset description 
Customer table 
orders table 
order_items_table 
order_payment table 
products_table 
sellers table 

# Business Problems 
1. identify top revenue generating product
2. Analyze customer order behavior ( repeat Vs one time )
3. Evaluate seller performance and revenue concentration
4. undertsnading pricing impacton total sales

# Tool used and Workflow 
  SQL (SSMS)
  1. Data Exploration
     - Rows counts  and unique entity checks 
     - Understanding relationship btween table 
  2. Core Sql Analysis
     - Joins between tables
     - aggeration to understand the seller- order , cutomer order realtionship
  3. Advance SQL Analysis
     - created table through with ( CTE)
     - Case statement
     - Window function for ranking
  4. Business Probem solving
     - Revenue by product categories
     - Top customers
     - price impact on revenue
     - seller performance 

# Key Insights 
1. A small set of product categories contibutes majority of platform revenue
2. reapet customers generate significantly higher revenue than one time buyers 
3. revenue is highly concerntrated among top performing sellers
4. mid range price product contribute the larger share of total sales
